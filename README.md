# Lede

A news reader built on one idea: instead of rating outlets "left" or "right,"
show **who owns them, what else that owner holds, and how the money flows** —
then link straight to the original articles so readers judge for themselves.

**Live at:** https://1902139.github.io/lede/

Built as an answer to the critique in *"Ground News and the War on Reality"*
(Literate Machine, 2026).

---

## What's in this repository

| File | What it does |
|---|---|
| `index.html` | The entire website — one file, no build step, no frameworks |
| `ownership.json` | **The editorial heart of the project.** 62 outlets: ownership chains, funding models, feed URLs, and accountability records |
| `fetch_news.py` | Pulls every RSS feed, groups articles covering the same story, writes `stories.json` |
| `stories.json` | Generated hourly. Don't edit by hand — the robot overwrites it |
| `analyze.py` | Optional article analysis (see below). Does nothing without an API key |
| `authors.json` | Generated by `analyze.py`. Empty until that's switched on |
| `.github/workflows/update.yml` | The hourly robot that runs it all |

## How it runs

A GitHub Action fires every hour, pulls ~72 feeds, clusters articles into
stories, and commits the result. GitHub Pages serves the site. No server,
no database, no cost.

Nothing needs doing to keep it alive.

## The five ownership classes

| Class | Meaning |
|---|---|
| Corporate | Owned by a conglomerate with holdings beyond news |
| Billionaire / family | Controlled by an individual or family, often via special voting shares |
| Worker-owned | The journalists own the outlet |
| Nonprofit | Foundation, trust, or donor funded |
| Public / state | Funded by a government or licence fee |

A story is flagged **underreported** when its coverage is concentrated outside
corporate and billionaire-owned outlets — the shape of story that tends to go
missing from the biggest feeds.

## Accountability records — what they are and aren't

Each outlet file lists documented incidents: retractions, fabrication findings,
defamation settlements, with years and sources, plus whether the outlet
publishes a corrections policy.

**These are not scores.** There is deliberately no "factuality percentage"
anywhere in this project. Verifying claims credibly requires human review, and
an invented number would be exactly the opaque rating this site exists to
replace.

**An empty record is not a gold star.** A 4-year-old worker-owned outlet has a
shorter history than a 170-year-old newspaper. Absence of incidents usually
reflects age and size, not virtue.

## Maintaining it

**Fixing a broken feed.** Feed URLs move. Check the Actions log for lines
starting `FAILED:`, then correct that outlet's `feeds` entry in
`ownership.json`. Some hosts block automated readers entirely — those are
worth giving up on.

**Adding an outlet.** Copy any existing block in `ownership.json` and fill in
the ownership chain, funding model, and feed URL. Choose the ownership class
honestly; that's the whole product.

**Stories grouped wrongly.** Clustering matches headline words and is
imperfect by nature. In `fetch_news.py`, raise `JACCARD_JOIN` (0.20 → 0.28) to
group less eagerly, or lower it to group more.

**Correcting an ownership entry.** Ownership changes. If something here is
wrong, it should be fixed — that's the point of publishing the database
openly.

## Optional: article analysis

`analyze.py` can classify each article (news / opinion / analysis), flag
framing in headlines, detect which source types a piece leans on, and build
author pattern profiles. It uses the Claude API — roughly $0.10–$2/month at
this scale.

To switch it on: add a repository secret named `ANTHROPIC_API_KEY` under
Settings → Secrets and variables → Actions. The workflow already looks for it
and skips the step silently when it's absent.

Test it without a key: `python analyze.py --mock`

## Running locally

```bash
pip install feedparser
python fetch_news.py
python -m http.server        # then open http://localhost:8000
```

Opening `index.html` by double-click won't load data — browsers block local
file reads. Use the server command above.

## Legal posture

Lede shows headlines and links out; full article text stays with the
publishers. That's standard aggregator practice. Ownership notes are
summaries of public record, simplified for readability. (Not legal advice.)
